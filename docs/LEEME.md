# Prototipo web jugable (HTML5)

`index.html` es el prototipo jugable de Guardianes de la Naturaleza: Patagonia (Aventuras de Guardaparques): un solo archivo, sin dependencias.
GitHub Pages sirve esta carpeta (`/docs`) para poder probarlo desde el celular con un link.

Para actualizar: reemplazar `index.html` por la nueva versión y hacer commit.

Herramientas de prueba (puntos extra, modo edición, sliders): agregar `?dev` al final del link.
